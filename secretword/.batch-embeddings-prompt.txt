## **Batch Embeddings Generator for 100 Secret Words**

You are tasked with creating an efficient batch processor to generate semantic embeddings for 100 secret words simultaneously. This approach loads the large embeddings file once and processes all words in memory for maximum efficiency.

### **Context & Performance Goal**
- `embeddings2.json` is 4.6GB and takes ~7 minutes to load
- Processing each word takes ~2 minutes once embeddings are in memory
- Goal: Process 100 secret words in ~207 minutes instead of 700 minutes (3.4x faster!)

### **Input Requirements**
1. **Secret Words List**: Either from `secretword/master-list.txt` or provided as arguments
2. **Embeddings File**: `.env/embeddings2.json` (114,103 word embeddings)
3. **Word List**: `data/enable2.txt` (114,430 words)

### **Output Requirements**
For each secret word, generate: `secretword/embeddings-[word].txt`
Format: `rank similarity word` (space-separated, ranked by similarity descending)

**Critical Requirements for 100-Word Processing**:

1. **Memory Management**:
   - Monitor memory usage throughout entire batch
   - Warn if memory usage exceeds 80% of available RAM
   - Provide clear error if system runs out of memory
   - Consider memory cleanup between words if needed

2. **Progress & ETA Accuracy**:
   - Update ETA every 10 words processed
   - Account for variable processing times per word
   - Show percentage completion for long batches
   - Display time elapsed and time remaining

3. **Robust Error Handling**:
   - Log failed words to `batch_errors.log`
   - Continue processing remaining words if individual failures occur
   - Provide summary of successful vs failed processing
   - Allow resuming from last successful word

4. **Skip Logic**:
   - Check if `embeddings-[word].txt` already exists before processing
   - Provide option to overwrite existing files or skip
   - Show count of skipped vs processed words

5. **Interruption Handling**:
   - Handle Ctrl+C gracefully without corrupting files
   - Show progress made before interruption
   - Provide command to resume from where it left off

6. **Performance Monitoring**:
   - Track processing speed (words/minute)
   - Identify slow words and log performance metrics
   - Report final statistics (total time, avg time per word, etc.)

**Memory Requirements**:
- Base embeddings2.json: ~6.8 GB in memory
- Working memory for calculations: ~1-2 GB
- **Recommended minimum RAM**: 12 GB
- **Optimal RAM**: 16+ GB

**Batch Size Considerations**:
- For systems with limited RAM (<12 GB), process in smaller batches of 25-50 words
- For high-memory systems (32+ GB), can process 200+ words in single batch
- Monitor memory usage and adjust batch size dynamically

**Expected Performance Gains**:
- **Serial Processing**: ~700 minutes (7min load × 100 words + 2min process × 100)
- **Batch Processing**: ~207 minutes (7min load × 1 + 2min process × 100)
