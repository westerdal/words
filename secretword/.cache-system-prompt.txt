## **OpenAI Clue Cache System Implementation**

### **Objective**
Create a persistent caching system to store OpenAI API responses for clue generation. This prevents redundant API calls when processes restart, significantly reducing processing time and API costs.

### **Cache Structure**
**File Format**: `secretword/[secretword]-cache.json`
**JSON Structure**:

### **Implementation Requirements**

#### **1. Cache Loading & Initialization**
```python
class ClueCache:
    def __init__(self, secret_word: str):
        self.secret_word = secret_word
        self.cache_file = f"secretword/cache-{secret_word}.json"
        self.cache = self.load_cache()
        self.hits = 0
        self.misses = 0
        self.api_calls_saved = 0
        
    def load_cache(self) -> Dict:
        """Load existing cache or create new one"""
        if os.path.exists(self.cache_file):
            with open(self.cache_file, 'r') as f:
                return json.load(f)
        return self.create_empty_cache()
```

#### **2. Cache Lookup Logic**
**Before any OpenAI API call**:
1. Check if `guess_word` exists in `cache["clues"]`
2. If found: return cached result, increment `hits`
3. If not found: make API call, cache result, increment `misses`
4. Auto-save cache every 50 new entries

#### **3. Cache Validation & Integrity**
- **Prompt Hash**: Store hash of current prompt to detect changes
- **Model Validation**: Ensure same model was used for cached entries
- **Rank Consistency**: Verify rank hasn't changed significantly
- **Expiration**: Optional TTL for cache entries (e.g., 30 days)

#### **8. Batch Cache Operations**
```python
def cache_batch_lookup(self, words: List[str]) -> Tuple[Dict, List[str]]:
    """Return cached results and list of words needing API calls"""
    cached_results = {}
    api_needed = []
    
    for word in words:
        if word in self.cache["clues"]:
            cached_results[word] = self.cache["clues"][word]
            self.hits += 1
        else:
            api_needed.append(word)
            self.misses += 1
    
    return cached_results, api_needed
```

#### **10. Debugging & Analytics**
```python
def get_cache_stats(self) -> Dict:
    """Return comprehensive cache statistics"""
    return {
        "total_entries": len(self.cache["clues"]),
        "hit_rate": self.hits / (self.hits + self.misses) if (self.hits + self.misses) > 0 else 0,
        "estimated_time_saved_minutes": self.api_calls_saved * 2.5,  # Avg 2.5s per API call
        "cache_size_mb": os.path.getsize(self.cache_file) / 1024 / 1024,
        "most_violated_words": self.get_most_violated_words(),
        "fastest_cached_words": self.get_fastest_responses(),
        "cache_age_days": (datetime.now() - datetime.fromisoformat(self.cache["metadata"]["created_at"])).days
    }
```
